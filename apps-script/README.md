# スプレッドシート同期の設定

アプリと Google スプレッドシートをつなぐと、次のことができるようになります。

- シートの **「ToDo・実績」** に書いた予定（と復習日）が、アプリのカレンダーとタイマー画面に出る
- アプリで計測した勉強時間・休憩が、同じスプレッドシートの **「アプリ記録」** タブに自動で書き込まれる
- アプリの予定の ✓ で、「ToDo・実績」の達成（H列）に「〇」、復習なら済チェックが付く（「ToDo・実績」に書くのはこの2つだけ。スクリプト v6 から）
- レポートのひとことが **「アプリメモ」** タブに書き込まれる（スクリプト v6 から）

## 設定手順（最初の1回だけ・5〜10分）

1. 同期に使うスプレッドシートを開く
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初からある `コード.gs` の中身を全部消し、このフォルダの [`Code.gs`](./Code.gs) の中身を貼り付ける
4. `TOKEN` を自分だけの合言葉に書き換えて保存（💾）する
   - 例：`const TOKEN = 'kaikei-2027-xxxx';`（他人に推測されにくい文字列にする）
5. 右上の **デプロイ → 新しいデプロイ** を開き、次のように設定して **デプロイ** を押す
   - 種類の選択（⚙️）：**ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「承認が必要です」と出たら、自分のアカウントを選んで許可する
   - 「このアプリは Google で確認されていません」と出たら **詳細 → （プロジェクト名）に移動** を押して許可する（自分で作ったスクリプトなので問題ありません）
6. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピーする
7. アプリの **⚙️ 設定 → スプレッドシート同期** に URL と合言葉を入れて **接続する** を押す
   - 「つながりました」と出れば完了

> 「アクセスできるユーザー：全員」にしても、合言葉を知らない人はデータを読み書きできません。
> URL と合言葉は人に教えないでください。

## スマホだけで設定する場合

スマホでスプレッドシートを開くとアプリが起動して「拡張機能」が使えないときは、スクリプトを単体で作ります。

1. ブラウザ（Safari / Chrome）を **PC版表示** にして https://script.google.com を開く
   - iPhone：アドレスバーの「ぁあ」→「デスクトップ用Webサイトを表示」
   - Android：右上の「⋮」→「PC版サイト」
2. **新しいプロジェクト** を作り、中身を全部消して `Code.gs` を貼り付ける
3. `TOKEN` に合言葉、`SPREADSHEET_ID` に同期するスプレッドシートの ID（URL の `/d/` と `/edit` の間）を入れて保存する
4. 上の手順の 5〜7（デプロイとアプリへの入力）を行う
   - iPhone で貼り付けのメニューが出ないときは、**3本指で画面をタップ** すると上に出るバーの 📋 で貼り付けられる

## 対応しているシートの形

このスクリプトは「CPA学習計画シート」の形に合わせてあります。

- **ToDo・実績**（5行目から1行1タスク）
  - A 日付 / B 分類 / C 科目 / D 種類・やること / F 計画(分) / G 実績(分) / H 達成 / I メモ / J 復習する / K〜R 復習①〜④の日付と済
  - 各行がアプリのカレンダーとタイマー画面に予定として出ます。「復習する」に✓がある行は、復習①〜④の日付にも出ます
- **設定** の C4 以下（科目の一覧）
  - アプリの ⚙️ 設定の「シートの科目に合わせる」で、アプリの科目をこの一覧に揃えられます

## 計測した時間の書き込み先

- **アプリ記録** タブ（最初の書き込みのときにスクリプトが自動で作ります）に、1回の計測ごとに1行ずつ入ります
  - ID / 日付 / 種類（勉強・休憩）/ 科目 / 開始 / 終了 / 分 / 手動 / やること
  - 予定の「▶ 開始」から計測したときは、「やること」にその予定の内容が入ります
- アプリで記録を直したり消したりすると、同じ行が書き換わったり消えたりします。**このタブは手で編集しないでください**
- 「ToDo・実績」の 実績(分) には書き込みません。勉強時間はアプリ記録とアプリの記録タブで見ます

## スクリプトを更新したとき

`Code.gs` を貼り直したら、**デプロイ → デプロイを管理 → ✏️ 編集 → バージョン：新しいバージョン → デプロイ** を行ってください。URL は変わりません。
