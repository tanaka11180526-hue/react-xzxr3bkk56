# スプレッドシート同期の設定

アプリと Google スプレッドシートをつなぐと、次のことができるようになります。

- シートの **「予定」** に書いた予定が、アプリのカレンダーとタイマー画面に出る
- アプリで計測した勉強時間・休憩が、シートの **「記録」** に自動で書き込まれる

## 設定手順（最初の1回だけ・5〜10分）

1. 同期に使うスプレッドシートを開く
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初からある `コード.gs` の中身を全部消し、このフォルダの [`Code.gs`](./Code.gs) の中身を貼り付ける
4. 11行目の `TOKEN` を、自分だけの合言葉に書き換えて保存（💾）する
   - 例：`const TOKEN = 'kaikei-2027-xxxx';`（他人に推測されにくい文字列にする）
5. 上の関数の選択欄で **`setup`** を選び、**▶ 実行** を押す
   - 「承認が必要です」と出たら、自分のアカウントを選んで許可する
   - 「このアプリは Google で確認されていません」と出たら **詳細 → （プロジェクト名）に移動** を押して許可する（自分で作ったスクリプトなので問題ありません）
   - シートに「予定」「記録」タブができていれば成功
6. 右上の **デプロイ → 新しいデプロイ** を開き、次のように設定して **デプロイ** を押す
   - 種類の選択（⚙️）：**ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
7. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピーする
8. アプリの **⚙️ 設定 → スプレッドシート同期** に URL と合言葉を入れて **接続する** を押す
   - 「つながりました」と出れば完了。これまでの記録もシートに送られます

> 「アクセスできるユーザー：全員」にしても、合言葉を知らない人はデータを読み書きできません。
> URL と合言葉は人に教えないでください。

## スマホだけで設定する場合

スマホでスプレッドシートを開くとアプリが起動して「拡張機能」が使えないときは、スクリプトを単体で作ります。

1. ブラウザ（Safari / Chrome）を **PC版表示** にして https://script.google.com を開く
   - iPhone：アドレスバーの「ぁあ」→「デスクトップ用Webサイトを表示」
   - Android：右上の「⋮」→「PC版サイト」
2. **新しいプロジェクト** を作り、中身を全部消して `Code.gs` を貼り付ける
3. `TOKEN` に合言葉、`SPREADSHEET_ID` に同期するスプレッドシートの ID（URL の `/d/` と `/edit` の間）を入れて保存する
4. 上の手順の 6〜8（デプロイとアプリへの入力）を行う。シートの見出しが無い場合は先に `setup` を実行する

## 「予定」シートの書き方

| 日付 | 開始 | 終了 | 科目 | 内容 | メモ |
|---|---|---|---|---|---|
| 2026/10/08 | 9:00 | 11:00 | 財務会計 | 連結 計算問題10問 | |
| 2026/10/08 | | | 租税 | 法人税 理論暗記 | 第3章まで |

- **日付** だけは必須。それ以外は空欄でも大丈夫です
- **科目** はアプリの科目名（例：財務会計）か略称（例：財務）を書くと、その科目の色で表示され、タイマー画面の「▶ 開始」で計測を始められます
- アプリは起動したとき・画面に戻ったとき・カレンダーの「↻ 更新」を押したときに予定を読み込みます

## 「記録」シートについて

アプリが自動で書き込みます。**手で編集しないでください**（アプリで記録を直すと、シートも同じ行が上書きされます）。

| 列 | 内容 |
|---|---|
| ID | 記録ごとの番号（アプリが使う） |
| 日付 / 開始 / 終了 | いつ勉強したか |
| 種類 | 勉強 / 休憩 |
| 科目 | 科目名 |
| 分 | 時間（分） |
| 手動 | 手動で追加した記録なら ○ |

## スクリプトを更新したとき

`Code.gs` を貼り直したら、**デプロイ → デプロイを管理 → ✏️ 編集 → バージョン：新しいバージョン → デプロイ** を行ってください。URL は変わりません。
